# roadmaps

Roadmaps is a library to manage curated roadmaps, allowing to include metadata in the task creation to order, prioritize and mark optional tasks. It also includes a CLI to interact with files including `RoadMap` representations.

- Optional tasks? Use `*` instead of `-`
- High priority? Append `!` after the checkbox (`[]!`). This task will be prioritized over all non-urgent tasks. In case of tie, prefer ordered items over unorder ones.
- Priority order? Append `^INT` after the checkbox `[]^2`. This task has priority 2. Order: `!` (urgent) > `^1` > `^2` > ... > rest of actions.
